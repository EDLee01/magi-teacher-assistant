# Magi 教师助手桌面端

桌面端面向一线物理教师，采用“项目 + Session + 对话 + 可查看模块”的结构。教师只需打开一个应用，不需要理解端口、Token 或后端进程。

## 启动

需要 Node.js 22 或更高版本：

```bash
npm install
npm run teacher:desktop
```

首次安装会下载 Electron 运行文件。打开应用后，点击左下角“模型设置”，填写 OpenAI 兼容接口地址、API Key 和模型名称即可开始对话；不需要在终端编辑配置。

接口地址和模型名称会写入独立的 `physics-teacher` 模型配置，不会覆盖 Magi CLI 原有的 `main` 模型。API Key 使用 Electron 提供的系统加密能力单独保存，不进入 `config.yaml`、项目目录或 Renderer。再次打开设置时，留空 Key 表示继续使用已保存的值。

## 界面结构

| 区域      | 教师看到的内容                                                            |
| --------- | ------------------------------------------------------------------------- |
| 教学项目  | 一个班级或一项长期教研工作，保存班级信息和跨 Session 记忆                 |
| 最近工作  | 集中考试分析、教师备课、练习调整、复测回顾等独立 Session                  |
| 对话      | 围绕当前 Session 连续讨论，自动带入当前项目上下文和资料检索结果           |
| 本次资料  | 点击输入框左侧 `＋` 临时添加，最多 5 份，只用于当前消息，不加入项目资料   |
| 权限范围  | 输入框下方选择项目内读写、只读或操作前询问；扩大操作时使用系统审批框      |
| 项目资料  | 可以多选文件或直接导入整个文件夹；主进程批量读取并去重，所有 Session 共用 |
| Magi Wiki | 导入后自动生成分类目录和资料来源页，对话可按目录检索并回到原文件核对      |
| 项目记忆  | 查看正式记忆，确认或拒绝待写入的学情和教学建议                            |
| 模型设置  | 配置 OpenAI Chat Completions 兼容接口、API Key 和模型名称                 |

## 前后端连接方式

Electron 主进程启动后，会完成以下工作：

1. 创建 Magi 物理教师 Runtime，并打开项目、Session 和记忆存储。
2. 在随机本机端口启动 REST 后端，并生成仅本次应用运行有效的 Bearer Token。
3. 通过隔离的 preload bridge 暴露有限的教学 API 和原生文件选择器。
4. Renderer 只通过 IPC 调用主进程，不持有 Token，也不能直接访问 Node.js 或任意网络地址。
5. 应用退出时关闭 HTTP 服务和数据库连接。

桌面端使用 Electron/Node 自带的 SQLite 驱动，普通 Magi CLI 继续使用原有数据库驱动。两者使用同一份表结构和 Service，不会因为 Electron 与系统 Node 的原生模块 ABI 不同而互相覆盖。

## 数据边界

- 真实教材、试卷、成绩和答题明细写入仓库外的私有运行目录。
- 输入框 `＋` 添加的资料只在回答当前消息时暂存，回答结束立即删除，不计入项目资料。
- 项目文件夹会递归导入支持的资料格式，自动忽略隐藏目录、代码依赖目录和不支持的文件。
- 相同内容使用 SHA-256 去重；知识库只保存于项目私有目录，不进入代码仓库。
- 上传资料不会进入 Git；项目初始化的 `.gitignore` 会排除 `uploads/`、运行状态和产物。
- 资料 API 只保存密钥环境变量名，真实密钥由运行环境提供。
- 模型 API Key 经系统能力加密保存，界面只能看到“已配置”状态，不能读回 Key。
- Renderer 不读取实际存储路径，REST 返回也会移除私有路径。
- 新学情先成为 Memory Draft，只有教师确认后才进入跨 Session 的项目记忆。
- “项目内读写”可直接写入 `workspace/` 和 `artifacts/`，上传原件、正式记忆和项目外路径始终不可写。
- “操作前询问”会在写文件、编辑文件、运行命令或暂存 Git 变更前弹出原生审批框，只批准当前一次操作。

## 验证

```bash
npm run test:teacher-desktop
```

该测试会实际启动 Electron，在临时目录中完成文件夹扫描、新建项目、新建 Session、发送对话、保存模型设置、上传资料、生成 Wiki 和确认记忆，结束后删除测试数据。

教师 Skill 的隐式调用业务测试：

```bash
npm run test:teacher-skill
```

该测试使用不包含 Skill 名称的考试分析请求，验证模型首轮能看到业务 Skill 摘要，隐式加载 `physics-exam-analysis` 的完整流程，并在拿到 Skill 结果后继续回答。
